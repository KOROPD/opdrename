PRESSROOM 파일명 일괄변경

폴더를 선택하고 규칙을 적용한 뒤 미리보기에서 확인한 다음 실제 파일명을 변경합니다. 서버 업로드 없이 사용자의 브라우저 안에서만 처리됩니다.

무료 배포용 · Chrome/Edge 권장 · HTTPS 필요
서버 업로드 없음선택한 폴더의 파일명만 브라우저에서 직접 변경합니다.
실행 전 미리보기중복·충돌 파일명을 먼저 확인한 뒤 실행합니다.
되돌리기 지원방금 작업은 되돌릴 수 있고 CSV 로그 저장이 가능합니다.
현재 브라우저는 폴더 쓰기 권한 API를 지원하지 않습니다. 데스크톱 Chrome 또는 Edge에서 실행해 주세요. 일부 환경에서는 index.html을 직접 열기보다 실행_웹앱.bat으로 localhost 실행이 필요합니다.

변경 규칙

브라우저 권한 창에서 파일 수정 권한을 허용해야 실제 변경이 가능합니다.
